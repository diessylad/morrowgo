# emil-design-eng

Read ../morrowgo-design/SKILL.md first. Explicit MORROWGO scope and current branding outrank upstream defaults.

Make frequent actions fast and calm. Give controls immediate 100–160ms press feedback; popovers 150–220ms, modal entrance 200–300ms. Use existing motion/react and easing tokens. Never animate from scale zero or block interaction behind entrance animation. Match user intent rather than mandatory new animation. Audit rendered interfaces; explain changes in a Before/After/Why table when reviewing.
